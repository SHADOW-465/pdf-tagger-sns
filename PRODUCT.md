# Product

## Register

product

## Users
Academic publishers, university accessibility librarians, government compliance officers, and digital preservation teams converting raw PDF ebooks and scanned manuscripts into ISO 14289-1 (PDF/UA) and WCAG 2.1 AA compliant publications.

## Product Purpose
Accessible Ebook Tagger provides an interactive, client-side, 3-pane power workspace for automated semantic structure inference, topological reading-order repair, AI alt-text generation, interactive audio speech simulation, automated compliance validation, and standards-compliant PDF/UA + EPUB-ready export with zero server data retention.

## Brand Personality
Precise, dependable, accessible, professional-grade workstation aesthetics. Designed with calm editorial authority, clear visual hierarchy, and tactile semantic feedback.

## Anti-references
- Cluttered SaaS templates with low-contrast pastel badges.
- Generic un-styled browser controls and unaligned panels.
- Jarring gradient text or decorative gimmicks that obscure semantic information.
- Inaccessible low-contrast grays or tiny unreadable font sizes.

## Design Principles
1. **Accessibility First (Practice What You Preach)**: The tagging interface itself must meet AAA/AA contrast, visible focus rings, aria labels, and 100% keyboard accessibility.
2. **Precision & Density with Breathing Room**: Information-dense multi-pane layout with clean visual hierarchy, clear tag badge contrast, and unambiguous reading order indicators.
3. **Immediate Feedback & Auditory Verification**: Changes to tags, reading order, and alt text instantly re-evaluate compliance metrics and update synchronized audio simulation.
4. **Resilient & Ergonomic Editors**: Seamless keyboard shortcuts, rich tag inspectors with inline semantic explanations, quick auto-fix actions, and smooth canvas zoom/pan.

## Accessibility & Inclusion
- WCAG 2.1 Level AA/AAA compliance across all interface controls.
- Full keyboard navigation with visible focus indicators (`focus-visible`).
- High-contrast semantic tag badges and state indicators.
- Respect `prefers-reduced-motion` for transitions and animations.
